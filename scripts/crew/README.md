# 🖖 Crew Scripts

Scripts related to crew coordination, quantum physics identities, and health diagnostics.

## Structure

```
scripts/crew/
├── coordination/     # Crew coordination and analysis scripts
├── quantum/          # Quantum physics identity scripts
├── health/           # Health and diagnostic scripts
└── README.md         # This file
```

## Coordination Scripts

- `crew-youtube-analysis-to-rag.js` - Coordinate crew analysis of YouTube videos
- `crew-observation-lounge-quantum-synopsis.js` - Generate Observation Lounge briefings

## Quantum Scripts

- `crew-quantum-physics-identity-propagation.js` - Map quantum physics to crew identities

## Health Scripts

- `crew-dr-crusher-mcp-health-diagnosis.js` - MCP server health diagnostics

## Usage

```bash
# Crew YouTube analysis
node scripts/crew/coordination/crew-youtube-analysis-to-rag.js payload.json

# Quantum identity propagation
node scripts/crew/quantum/crew-quantum-physics-identity-propagation.js

# Health diagnosis
node scripts/crew/health/crew-dr-crusher-mcp-health-diagnosis.js
```
