## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- Docker and Docker Compose
- PostgreSQL 14+
- Redis 6+

### Installation
```bash
npm install
npm run dev
```

### Development
```bash
# Start development server
npm run dev

# Run tests
npm test

# Build for production
npm run build
```
