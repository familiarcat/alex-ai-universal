## 🎯 **How to Use Examples**

### **1. Explore the Demo Project**
Start with the demo project to understand the full capabilities:

```bash
cd examples/demo-project
cat foundation-conversation.md  # Read the original conversation
node index.js                   # Run the full demonstration
cat README.md                   # See generated project documentation
```

### **2. Understand the Process**
The demo project shows the complete flow:
1. **Text Conversation** → Foundation conversation about smart home automation
2. **Crew Analysis** → All 6 crew members provide specialized recommendations
3. **Project Generation** → Complete project structure created automatically
4. **Universal Integration** → All Alex AI features available immediately
5. **Documentation** → Comprehensive project documentation generated

### **3. Apply to Your Projects**
Use the patterns from the demo project to initialize your own projects:

```bash
# In your project directory
npx @alex-ai/core universal-init
```
