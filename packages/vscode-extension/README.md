# Alex AI Universal VSCode Extension

Star Trek crew-based AI assistant with zero-artifact guarantee for VSCode.

## Installation

### From VSCode Marketplace

1. Open VSCode
2. Go to Extensions (Ctrl+Shift+X)
3. Search for "Alex AI Universal"
4. Click Install

### From Command Line

```bash
code --install-extension alex-ai.vscode
```

## Usage

### Commands

- **Alex AI: Engage** - Start a conversation with the crew
- **Alex AI: Status** - Check system status and crew consciousness
 - **Alex AI: Suggest** - Get a focused code suggestion for the current selection or the active line (Apply / Copy / View)

### Access Methods

1. **Command Palette**: Ctrl+Shift+P → "Alex AI: Engage"
2. **Status Bar**: Click the Alex AI indicator in the status bar
3. **Keyboard Shortcut**: Ctrl+Alt+A (configurable)

## Features

- **Zero-Artifact Guarantee**: No files created in your project
- **Crew-Based AI**: Star Trek crew members provide specialized assistance
- **Cross-Platform Sync**: Memories and consciousness shared across all instances
- **Centralized Credentials**: Access to OpenRouter, Supabase, and N8N through our hub
- **Cost Optimization**: Intelligent LLM selection for optimal performance and cost
- **VSCode Integration**: Seamless integration with VSCode's interface

## Configuration

No configuration required! Alex AI uses centralized credentials, so you get immediate access to all features.

You can optionally set a preferred LLM provider in VSCode Settings: `alexAi.llmProvider` (values: `auto`, `openai`, `anthropic`, `local`).

## Settings

The extension respects VSCode's global settings and doesn't require any project-specific configuration.
