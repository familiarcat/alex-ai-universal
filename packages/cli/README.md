# Alex AI Universal CLI

Star Trek crew-based AI assistant with zero-artifact guarantee for NPX usage.

## Installation

```bash
# Install globally
npm install -g @alex-ai/cli

# Or use directly with NPX
npx @alex-ai/cli engage "Hello crew!"
```

## Usage

### Basic Commands

```bash
# Engage Alex AI with a message
npx alex-ai engage "Help me debug this code"

# Start interactive chat session
npx alex-ai chat

# Check system status
npx alex-ai status
```

### Interactive Chat

```bash
npx alex-ai chat
```

This starts an interactive chat session where you can:
- Type messages to engage the crew
- Type `help` for available commands
- Type `exit` to end the session

## Features

- **Zero-Artifact Guarantee**: No files created in your project
- **Crew-Based AI**: Star Trek crew members provide specialized assistance
- **Cross-Platform Sync**: Memories and consciousness shared across all instances
- **Centralized Credentials**: Access to OpenRouter, Supabase, and N8N through our hub
- **Cost Optimization**: Intelligent LLM selection for optimal performance and cost
