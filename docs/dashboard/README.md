## 🚀 Getting Started

The dashboard is automatically integrated into all Alex AI projects. No manual setup required!

1. Create a new project via `/projects/new`
2. Dashboard components are automatically added
3. Drag-and-drop is enabled by default
4. ProjectManager component is included

See [DASHBOARD_INTEGRATION.md](./DASHBOARD_INTEGRATION.md) for details.
