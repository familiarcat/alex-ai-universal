# 🖖 Cursor AI Quick Start - Alex AI Integration

**Get started with Alex AI crew memories in 30 seconds**

---

## ⚡ One-Command Setup

```bash
npm run cursor:prompt
```

This generates a complete startup prompt with all crew memories.

---

## 📋 Three Steps to Activate

### Step 1: Generate Prompt
```bash
npm run cursor:prompt
```

### Step 2: Open File
Open `.cursor/alex-ai/cursor-startup-prompt.md`

### Step 3: Copy & Paste
Copy entire contents → Paste into Cursor AI chat → Start working!

---

## 🎯 What You Get

✅ All crew member memories loaded  
✅ Full context from previous sessions  
✅ Crew coordination activated  
✅ Memory persistence enabled  

---

## 🔄 Keep Memories Updated

Run before each session:
```bash
npm run cursor:prompt
```

Or just load memories:
```bash
npm run cursor:memories
```

## 💡 Pro Tips
