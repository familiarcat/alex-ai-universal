# 🎨 UI Design Vector Experiment

**Date:** November 24, 2025  
**Status:** ✅ Implemented  
**Purpose:** Dashboard as extension of Supabase vector data with modern UI design scraping

---

## 📋 Overview

This experiment creates a system that:

1. **Scrapes modern UI designs** from design inspiration websites
2. **Analyzes aesthetic factors** (colors, mood, layout, etc.)
3. **Generates vector embeddings** for each design
4. **Stores in Supabase** as vector data
5. **Compares with existing dashboard designs** using vector similarity
6. **Generates new designs** based on aesthetic comparison

---

## 🎯 Aesthetic Factors

The system analyzes these factors for each design:

1. **Color Palette** - Dominant colors extracted from images
2. **Typography** - Font styles and hierarchy
3. **Spacing** - Layout spacing patterns
4. **Layout Structure** - Overall page structure
5. **Visual Hierarchy** - Information organization
6. **Interaction Patterns** - UI interaction styles
7. **Component Style** - Component design patterns
8. **Overall Mood** - Dark, bright, or balanced

---

## 🔄 Experiment Flow

### Step 1: Scrape UI Designs

Scrapes modern UI designs from:
- Dribbble
- Behance
- Awwwards
- Land-book
- SiteInspire

**Output:** Design images, titles, descriptions, source URLs

### Step 2: Analyze Aesthetics

For each design:
- Extract color palette from images
- Determine overall mood (dark/bright/balanced)
- Analyze layout structure
- Identify component styles

**Output:** Aesthetic analysis object

### Step 3: Generate Vector Embeddings

Creates vector embeddings using:
- OpenRouter embedding API (text-embedding-3-small)
- Fallback: Feature-based vector from design attributes

**Output:** 1536-dimensional vector embedding

### Step 4: Store in Supabase

Stores in `vector_embeddings` table:
- Vector embedding
- Design metadata
- Aesthetic analysis
- Source information

**Output:** Stored design records

### Step 5: Compare with Dashboard

Finds similar dashboard designs using:
- Vector cosine similarity
- Aesthetic factor matching
- Threshold: 0.7 similarity

**Output:** Similar dashboard designs with similarity scores

### Step 6: Generate New Designs

Creates hybrid designs by:
- Blending color palettes
- Combining moods
- Merging layout structures
- Combining component styles

**Output:** Generated design recommendations

## 🎨 Aesthetic Comparison

### Similarity Calculation

1. **Vector Similarity** (Primary)
   - Cosine similarity between embeddings
   - Threshold: 0.7

2. **Aesthetic Factor Matching** (Secondary)
   - Color palette overlap
   - Mood matching
   - Component style matching
   - Layout structure matching

### Design Generation

New designs are generated by:
- **Blending color palettes** - Combine colors from both designs
- **Mood blending** - Average or combine moods
- **Layout merging** - Combine layout structures
- **Style fusion** - Merge component styles

---

## 🔧 Technical Details

### Color Extraction

Uses Canvas API to:
1. Load design image
2. Sample pixels
3. Extract dominant colors
4. Create color palette

### Embedding Generation

**Primary Method:**
- OpenRouter embedding API
- Model: `text-embedding-3-small`
- Input: Design text description + aesthetic factors

**Fallback Method:**
- Feature-based vector
- Encodes: Colors, mood, layout, style
- Dimension: 1536 (padded)

### Vector Storage

Stored in Supabase `vector_embeddings` table:
- Indexed with IVFFlat for fast similarity search
- Metadata stored as JSONB
- Pattern type: 'ui_design'
