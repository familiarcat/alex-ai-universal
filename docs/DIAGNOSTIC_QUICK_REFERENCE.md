## 📊 Decision Guide

| Situation | Recommended Level |
|-----------|------------------|
| Critical system-wide issue | Level 1 |
| Security audit needed | Level 2 security |
| Performance problems | Level 2 performance |
| UX concerns | Level 2 ux |
| Routine health check | Level 3 |
| Pre-deployment validation | Level 1 |
| Daily monitoring | Level 3 |

---

## 💡 Tips

1. **Start with Level 3** for routine checks (best ROI)
2. **Use Level 2** for most issues (targeted, efficient)
3. **Reserve Level 1** for critical/system-wide problems
4. **Let Quark recommend** when unsure:
   ```bash
   ISSUE_SEVERITY=critical node scripts/diagnostic-system.js
   ```
